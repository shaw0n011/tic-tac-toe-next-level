📜 Game Rules

Rule 1 — Make a Line

A player must have their own sign in 3 connected boxes: horizontal, vertical, or diagonal.

Rule 2 — Point System
  • First use of a box = 1 point.
  • If the same player uses that box a second time = 1.5 points for that box.
  • If the other player uses it second, both players get 0.5 point in that box.
  • Third use is strictly forbidden.
Rule 3 — How to Win

Only the 3 boxes of the connected winning line are counted. Points from other boxes do not matter.

0.5 + 1 + 1 = 2.5 → ❌ No win
1 + 1 + 1 = 3 → ✅ Win

Special Box Marks

Double X: when X uses a box twice, the X changes into a large red ★ mark.

Double O: when O uses a box twice, it becomes a double-circle mark with ★.

Shared box: if X and O each use the same box once, both signs appear separately and the box shows ½ + ½.
